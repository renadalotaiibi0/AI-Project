# صانع باقات المنتجات — Zid / رِواق القهوة

تطبيق تجريبي عربي RTL لواجهة عميل مستقلة ولوحة تاجر مستقلة، يستخدم بيانات متجر رِواق القهوة الاصطناعية المرفقة بالحزمة. يظل Zid اسم المنصة، واسم المتجر المعروض بحسب ملف البيانات هو رِواق القهوة.

## الصفحات

- العميل: `index.html` — تصفح 30 منتجًا، تحديد ميزانية، بناء باقة، سلة وشراء وتتبع طلبات هذا المتصفح.
- التاجر: `merchant.html` — لوحة الأداء، المنتجات والمخزون والباقات وإدارة 240 طلبًا تجريبيًا، ومكتبة الأسئلة الشائعة، ويستقبل أسئلة العملاء من واجهة المتجر.
- صانع الأسئلة الشائعة: يقترح مسودات محليًا من الأسئلة المتكررة في بيانات الدعم والحقائق الموثقة للمنتجات. يراجع التاجر الإجابة وينشرها يدويًا؛ لا يتصل بخدمة ذكاء اصطناعي أو خدمة خارجية، ولا تظهر المسودات للعملاء. نموذج أسئلة المتجر يرسل السؤال إلى قائمة التاجر محليًا على المتصفح نفسه؛ مشاركة الأسئلة بين أجهزة مختلفة تتطلب قاعدة بيانات وخادمًا.

تبدأ البيانات من `data/store_complete.js` (2,747 سجلًا عبر 36 كيانًا، وتشمل 80 عميلًا و70 تقييمًا وبيانات التحليلات). البيانات خيالية ومعلّمة في الحزمة بأنها اصطناعية، وليست اتصالًا بخدمة زد أو بيانات متجر حقيقي. تبقى عمليات الشراء وتعديلات التاجر محلية في `localStorage` على الجهاز نفسه؛ لا يوجد دفع إلكتروني أو خادم مركزي.

ملفات صور الحزمة الأصلية لم تصل ضمن المرفقات؛ لذلك أُنشئ بانر تصويري للقهوة وصورتان محليتان منظمتان كشبكات للمنتجات، مع الحفاظ على الصور البديلة محلية وعدم ربطها بخدمات خارجية.

## التشغيل

شغّل من مجلد المشروع:

```bash
python3 -m http.server 8000
```

افتح `/index.html` للعميل و`/merchant.html` للتاجر من نفس عنوان الموقع كي تتزامن البيانات. الملفات `index.html` و`merchant.html` مستقلة وجاهزة أيضًا للمعاينة مباشرة.

بعد تعديل `app.js` أو `styles.css` أو القوالب، أعد توليد الصفحات المستقلة عبر:

```bash
python3 build_preview.py
```
